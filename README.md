# Internationalization

The `Internationalization` engine is mounted at `/internationalization`. It
provides English, French, and Spanish locale settings for the host application
and its engines. Guests keep their selected locale in a cookie; signed-in users
save it to account settings. Locale dictionaries and date/time/pluralization
rules are maintained in `app/engines/internationalization/config/locales`,
following the [Rails Internationalization guide](https://guides.rubyonrails.org/i18n.html).

Store products support translated names and rich-text descriptions for French
and Spanish, managed with the product form.
